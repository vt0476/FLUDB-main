# Dados

A base de partidas é obtida por `scripts/download_data.py` da fonte pública indicada no README principal. Dados brutos e tratados não são versionados neste repositório: execute o pipeline para recriá-los. O relatório de qualidade registra o volume obtido, duplicatas e linhas inválidas. Consulte a licença/termos da fonte antes de redistribuir.
